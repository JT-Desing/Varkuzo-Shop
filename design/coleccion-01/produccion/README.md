# Varkuzo / paquete de desarrollo para proveedores

Este directorio traduce los 30 looks conceptuales a instrucciones **para cotizar y confeccionar prototipos**. No autoriza corte de producción: faltan patrón físico, muestra aprobada, prueba de lavado, color aprobado y artes finales de cada gráfica.

## Archivos

- `matriz-30-looks.csv`: por referencia, piezas, tejidos objetivo, color, técnica y entregables que debe presentar el taller.
- `medidas-base.csv`: medidas objetivo de muestra base M y tolerancias de evaluación. Son una propuesta de fit, no medidas verificadas en cuerpo real.
- `gradacion-propuesta.csv`: incrementos preliminares para S–XL. La gradación final depende del patrón y prueba de calce.
- `artes-y-ubicaciones.md`: reglas de entrega de artes e instrucciones de aplicación.
- `control-de-muestra.md`: protocolo de aprobación y cotización.

## Cómo utilizarlo

1. Entregar el PDF conceptual, los editables y esta carpeta al taller.
2. Escoger 4–6 looks para primera ronda y solicitar patrón, muestra M, ficha de tela y cotización detallada.
3. Corregir fit, gráfica y color sobre la prenda física. Registrar versión aprobada por referencia.
4. Solo entonces emitir orden de producción con tabla de tallas, materiales y artes aprobados.

Las fotos generadas son una dirección estética. El proveedor no debe intentar calcarlas como plano exacto ni deducir medidas, construcción o materiales a partir de sus píxeles.
